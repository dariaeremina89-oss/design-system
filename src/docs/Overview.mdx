# Тестовый плейбук дизайн-системы

Это моя тестовая дизайн-система и личный плейбук для проверки токенов, компонентов и подходов к реализации F.Doc в React и Storybook. Это не официальная библиотека F.Doc и не production-пакет.

## Как пользоваться библиотекой

В **General** собраны токены, типографика, иконки и общая документация. В **Components** — компоненты по назначению.

В Docs готовых компонентов доступны описание, пропсы, покрытие тестами и селекторы для тестирования. Сториз позволяют проверить размеры, состояния и варианты содержимого.

Готовые компоненты и разделы атомов отмечены галочкой ✓ в левом меню. У запланированных компонентов показана отметка «Еще не реализован».

## Типографика на мобильных

Компоненты используют именованные стили из General → Typography: Body, Subtitle, Caption и остальные. Их размер и межстрочный интервал постоянны на всех ширинах. Для текста страницы `Typography` с `responsive` включает существующий Mobile-вариант выбранного стиля. Глобального переключения токенов нет, поэтому вложенные компоненты сохраняют свою типографику.

Link и ButtonLink с `typography="inherit"` внутри абзаца наследуют его стиль, включая мобильное уменьшение. По умолчанию у ссылки собственный постоянный стиль, выбранный через size.
