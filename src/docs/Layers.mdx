# Слои

Токены слоев (`z-index`) задают порядок наложения элементов и помогают поддерживать единый стек интерфейса без случайных значений.

## Правила

- Используем только токены из UI Kit.
- Каждый слой предназначен для своего типа элементов.
- Не расширяем диапазон слоев без необходимости.
- Новый слой не может превышать `--layer-top` по значению.
- Новый слой не может быть меньше `--layer-hidden` по значению.
