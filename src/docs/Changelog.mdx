## 08.10.2026

### CodeInput

- Заглушка CodeInput заменена рабочим компонентом по Figma InputOtp / Type=Code.
- Поддержаны 4, 5 и 6 ячеек, размеры Medium 48×56 и Small 32×48, Label, Caption / Error, Required, Disabled и Skeleton.
- Реализованы controlled / uncontrolled value, авто-переход фокуса после ввода, Backspace, Arrow / Home / End и вставка полного кода с нормализацией цифр.
- Добавлены Docs, Controls, unit- и browser-проверки, public export и Quality contract.

### AsyncAutocomplete и AsyncMultiselect

- Async Menu приведен к продуктовым сценариям поиска: Idle → External Menu Message → Loading → Results → No Results → Load Error.
- Добавлен `menuMessage` для внешней обратной связи по поисковому запросу. Правила валидации не зашиты в компоненты: consumer сам определяет допустимые символы и форматы и решает, выполнять ли `onFetch`.
- Validation Error самого поля остается отдельным состоянием. В примере внешней валидации сообщение показывается внутри Menu, поле не становится красным, а выбранные Chips в AsyncMultiselect сохраняются.
- Product-specific Header/Footer из примеров убраны: async-компоненты показывают только универсальные состояния поиска.
- До достижения `minCharacters` оба async-компонента держат Menu открытым. `idleText` может быть обычной подсказкой о том, что вводить, или функцией для динамического текста «Введите еще N символов, чтобы начать поиск». Без переопределения используется динамический счетчик.
- В Load Error адрес support@fdoc.ru отображается настоящей mailto-ссылкой. Browser-тесты фиксируют типографику Menu по Figma: сообщения и title 14/20, description 12/16.

### PriceInput

- Заглушка PriceInput заменена рабочей специализацией Input без дублирования базовой геометрии и состояний.
- Добавлены группировка тысяч, запятая для копеек, символ валюты, Clear, нормализация Paste и normalized value для формы.
- Добавлены Figma-примеры Empty / Typing / Filled и три Error-сценария: Required, Limit и Validation Error.
- Counter считает только введенные цифры; добавлены helpers диапазона 1–9 999 999,99 ₽, Docs, Quality contract и unit/browser-проверки.

## 07.10.2026

### AsyncMultiselect

- Добавлен AsyncMultiselect для серверного поиска нескольких значений: `minCharacters`, `debounce`, `limit`, controlled/uncontrolled value и inputValue, Loading / Load Error / Empty, keyboard navigation и сохранение выбранных значений между ответами сервера через `selectedOptions`.
- После выбора нового значения поисковый запрос очищается, выбранное остается Chips, фокус возвращается в поле. Добавлен пример, где уже выбранные значения исключаются из следующих результатов Menu и остаются только Chips внутри поля.
- Default и Required в Storybook имитируют реальный async-поиск и показывают только совпавшие результаты. Добавлены unit- и browser-проверки жизненного цикла запроса, выбора и состояний.
- У Multiselect исправлен скачок высоты при удалении Chips: компенсация focus-border теперь включается только при фокусе текстового control.

## 06.10.2026

### Custom Branding / Brand-safe

- Разделены логика цвета текста `onPrimary` и слой интерактивных состояний Primary. Hover / Pressed больше не зависят от выбранной полярности текста.

- Добавлены проверки для зеленых и средне-красных Primary, чтобы состояния оставались различимыми, а foreground не переключался неожиданно.

## 18.09.2026

### Input

- Input доведен до полного field-контракта: Label, Required, Caption / Error, Counter, Leading / Trailing, Clear и состояния Focus / Hover / Disabled.
- Счетчик символов работает автоматически, длинные Label и helper text безопасно переносятся, focus-border имеет приоритет над Hover.
- Clear переиспользует ButtonIcon, а пустые optional slots не оставляют лишние отступы.

### Skeleton

- Добавлены typography-aware Skeleton и anatomy-aware Input Skeleton: Label, Required, Value, helper, icons и clear action заменяются отдельными skeleton-частями с геометрией исходных элементов.
- Общая wave-анимация централизована, высоты текста и иконок приведены к Figma.

### Button, ButtonIcon и индикаторы

- Добавлен ButtonIcon со всеми размерами и цветовыми состояниями; Neutral сохраняет корректный icon color во всех состояниях.
- Добавлен Button по Figma и его regression coverage; Loading использует progress indicator.
- Добавлены Badge и базовые Progress Indicators.

### Storybook

- Навигация сгруппирована по семействам компонентов и получила явный порядок разделов и stories.

## 17.09.2026

### Основа репозитория

- Инициализирован React / Storybook репозиторий дизайн-системы и добавлен первый Input.
- Синхронизирован полный каталог Figma Variables и базовые foundations: цвета, размеры, типографика, тени и другие атомарные токены.
- Добавлены страницы атомов и библиотека Icon; иерархия токенов разделена на уровни и namespace-группы по структуре Figma.

### Typography и темы

- Семантические typography tokens подключены к образцам, добавлены sans-serif fallback.
- Responsive typography ограничена page-level стилями: размеры текста внутри компонентов, включая Input, не уменьшаются на мобильных.
- Для цветовых токенов добавлен читаемый foreground в документации.
