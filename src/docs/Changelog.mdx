# Changelog

Обновления сгруппированы по дням, от новых к старым. Внутри дня — сводка по компонентам и разделам библиотеки.

## 21.09.2026

### Textarea и Input

- Реализована Textarea: два размера, состояния, многострочный ввод, переносы и прокрутка, вертикальное изменение высоты, счетчик и Skeleton. Добавлены примеры, Docs, селекторы и автотесты.
- Label, Helper, счетчик, связи доступности и общие стили состояний вынесены в общую основу Input и Textarea. Существующие API и селекторы Input сохранены.
- В Docs зафиксирован приоритет высоты 112 px из Figma над требованием четырех видимых строк.

### Button

- Уточнены типографика, порядок и размеры вложенных элементов, состояния бейджей. Добавлены независимые переключатели обеих иконок и обоих бейджей, примеры всех размеров с полным составом.

### CircularProgress и LinearProgress

- Обновлены настройки индикаторов и примеры. Для CircularProgress исправлены анимация дуги и цвета, размер по умолчанию — 24 px.
- В навигации выделены отдельные разделы для кругового и линейного прогресса.

### Typography и Layers

- Примитивы типографики сгруппированы по свойствам. Образцы стилей разделены на Desktop и Mobile.
- Добавлены правила наложения элементов и семь токенов слоев: от `--layer-hidden` до `--layer-top`.

### Структура библиотеки и документация

- Настроены разделы General и группы Components. Запланированные компоненты отмечены заглушками.
- Overview, Layers, Custom Branding и Changelog оформлены отдельными страницами документации. Исправлено отображение таблицы токенов в Overview.
- В Docs готовых компонентов добавлены сведения о тестах, пробелах в покрытии и селекторах. Браузерные проверки дополнены проверками структуры, документации и образцов типографики.
- Удалены ссылки на закрытые макеты Figma и идентификаторы узлов из документации компонентов.
